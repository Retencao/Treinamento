O _downgrade_ é uma opção de alívio financeiro rápido para o cliente: a gente reduz alguns serviços para baixar o valor da mensalidade.

 Por exemplo, se ele tem os adicionais de colisão e de vidros, você pode sugerir transferi-lo para o setor de [[CANAIS DE ATENDIMENTO/CADASTRO\|CADASTRO]] para retirar essas coberturas e abaixar o valor de sua mensalidade.
 
 
 
 IMPORTANTE: antes de sugerir o _downgrade_, cheque no sistema se o cliente realmente tem algum serviço adicional contratado. Só dá para oferecer essa opção se houver o que retirar para reduzir a mensalidade.
 
 
 
**Restrição para Aplicação de Downgrade:**

- **Impedimento por Processo em Aberto:** A realização do _downgrade_ só poderá ocorrer se não houver processos de [[PROCEDIMENTOS/COLISAO-E-VIDROS\|COLISAO-E-VIDROS]], [[PROCEDIMENTOS/INDENIZAÇÃO\|INDENIZAÇÃO]] ou [[PROCEDIMENTOS/JURIDICO\|JURIDICO]] em aberto.
